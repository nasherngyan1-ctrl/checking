# پلانی نوێکراوە: ئەپڵیکەیشنی پشکنەری بەرید بە وێنە (Visual Delivery Checker)

ئەم ئەپڵیکەیشنە بە تەواوی ئامادەکراوە بۆ کاری شۆفێر و کارمەندانی بەرید لە کوردستان، بە تایبەتی بۆ ئەو جۆرە لەزگە و پاکێجانەی وەک نموونەکەی نێردراو (لەزگەی دەستنووسی Postyar و هاوشێوەکانی).

## User Review & Critical Decisions

> [!IMPORTANT]
> **دەستکاری و جەختکردنەوە بەپێی تێبینی و وێنەی نێردراو:**
> 1. **لابردنی مەرجی بارکۆد:** وەک لە وێنەکەدا دەردەکەوێت، بارکۆد/QR سەر لەزگەکە نووسینی هاتووەتە سەر و پشتپێبەستراو نییە؛ بەڵکو تەواوی سیستەمەکە پشت بە **ناسینەوەی ڕاستەوخۆی وێنەی پاکێج و لەزگەکە (Visual Match + Text/Digits Recognition)** دەبەستێت.
> 2. **پڕۆسەی سەرەکی کارکردن (Workflow):**
>    - **بەیانیان / پێش وەختە:** گرتنی وێنەی هەموو پاکێجەکان و تۆمارکردنی نرخ و ناونیشان و ژمارەی مۆبایل.
>    - **لە کاتی گەیاندندا:** گرتنی وێنەی پاکێجەکە لە بەشی "پشکنین" -> ئەپەکە دەستبەجێ وێنەکە بەراورد دەکات، دەڵێت "کاڵاکە دۆزرایەوە"، نرخەکەی پێشان دەدات (وەک: 47,000 د.ع)، پەیوەندی بە کڕیار پێشنیاز دەکات.
>    - **لابردن لە ناو سیستەم:** بە داگرتنی دوگمەی "گەیەندرا"، دەستبەجێ لە لیستی چاوەڕوانی ڕۆژانە دەسڕێتەوە و دەچێتە بەشی ئەرشیفی گەیەندراوەکان.

---

## 1. پێناسەی ئەپ و ئەزموونی بەکارهێنەر (Overview & Core Concept)

- **چی دەکات:**
  - کۆمەڵێ کاڵات بۆ دێت؛ وێنەی هەموویان بە خێرایی لە ئەپەکە تۆمار دەکەیت لەگەڵ نرخەکانیان.
  - کاتێک پاکێجێک بە دەستتەوەیە، کامێرای ئەپەکە دەکەیتەوە و وێنەکەی دەگریتەوە؛ ئەپەکە لە ناو هەموو وێنە تۆمارکراوەکاندا هاوشێوەکەی دەدۆزێتەوە و نرخ و زانیارییەکانی دەردەهێنێت.
  - کاتێک گەیاندت، بە یەک کلیک دەڵێیت "گەیەندرا"، لە لیستی ڕۆژانە لادەبرێت و کۆی پارەی وەرگیراوت بۆ نوێ دەکاتەوە.
- **تایبەتمەندی دەستنووس و لەزگە:** ئەپڵیکەیشنەکە بە تایبەتی لەسەر شێوازی ئەو لەزگانە (وەک وێنەی هاوپێچ: ناونیشان، مۆبایل، نرخ، تێبینی) ڕێکدەخرێت.

---

## 2. ڕووکار و دیزاین بە زمانی کوردی (User Experience & Kurdish RTL UI)

- **ئاڕاستەی دیزاین:** ڕووکارێکی خێرا و مۆدێرن بە زمانی پاراوی کوردی (سۆرانی)، گونجاو بۆ کارکردنی خێرا بە یەک دەست:
  1. **شاشەی سەرەکی (پاکێجە چاوەڕوانەکان):**
     - کارتی ئامار لە سەرەوە: ژمارەی پاکێجی ماوە، کۆی پارەی شایستەی کۆکردنەوە (بۆ نموونە: 340,000 د.ع).
     - دوگمەی گەورەی زەق: **"📸 پشکنینی خێرای کاڵا بە وێنە"**.
     - لیستی وێنەی پاکێجە چاوەڕوانەکان بە کارتۆنی سەرنجڕاکێش و نرخی دیار.
  2. **شاشەی زیادکردنی پاکێج (تۆمارکردنی پێشوەختە):**
     - گرتنی وێنەی پاکێجەکە بە کامێرا یان هەڵبژاردن.
     - نووسینی نرخ (بە دیناری عێراقی IQD).
     - ناونیشان و ژمارەی مۆبایلی کڕیار (دەرهێنانی پێشنیارکراو یان نووسینی دەستی خێرا).
     - دوگمەی "پاشەکەوتکردن".
  3. **شاشەی پشکنین و بەراوردکردنی وێنە (Visual Match Camera):**
     - گرتنی وێنەی پاکێجەکەی بەردەستت.
     - ئەپ بە ئەلگۆریتمی شیکاری پێکهاتەی وێنە و ڕەنگ و ژمارەکان پشکنین دەکات:
       - **ئەگەر هاوتا بوو:** نیشاندانی دەستبەجێی کارتی کاڵاکە بە دڵنیایی بەرز، پیشاندانی نرخ (وەک: **47,000 د.ع**)، ناونیشان، و مۆبایل.
       - **دوگمەی سەرەکی سەوز:** "✅ گەیەندرا - لابردن لە سیستەم" (کاڵاکە دەگوازێتەوە بۆ بەشی تەواوکراوەکان).
       - دوگمەی پەیوەندی تەلەفۆنی خێرا بۆ کڕیار.
       - **ئەگەر هاوتا نەبوو:** نیشاندانی ئاگاداری ڕوون بە کوردی: "ئەم کاڵایە لە لیستی چاوەڕواندا نییە یان پێشتر گەیەندراوە".
  4. **ئەرشیف و مێژووی کاڵا گەیەندراوەکان:** بینینی هەموو ئەو کاڵایانەی لە سیستەم پاککراونەتەوە و کاتی گەیاندنیان.

## 3. تەلارسازی تەکنیکی و بزوێنەری ناسینەوەی وێنە (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────┐
│                    Jetpack Compose UI (Kurdish)             │
│  ┌────────────────┐ ┌────────────────┐ ┌─────────────────┐  │
│  │ Pending Parcels│ │ Add Parcel Form│ │ Visual Match Cam│  │
│  │ (Stats & List) │ │ (Photo + Price)│ │ (Take & Check)  │  │
│  └───────┬────────┘ └────────┬───────┘ └────────┬────────┘  │
└──────────┼───────────────────┼──────────────────┼───────────┘
           │                   │                  │
┌──────────▼───────────────────▼──────────────────▼───────────┐
│               ParcelViewModel & Visual Match Engine         │
│  - Image Perceptual Hashing & Structural Feature Match      │
│  - In-Memory & Room Local Cache                             │
└──────────┬──────────────────────────────────────────────────┘
           │
┌──────────▼──────────────────────────────────────────────────┐
│                 Room Database (Local SQLite)                │
│  - ParcelEntity: id, photoUri, price, address, phone,       │
│    status (PENDING / DELIVERED), createdAt, deliveredAt     │
└─────────────────────────────────────────────────────────────┘
```

- **بزوێنەری ناسینەوەی وێنە بەبێ بارکۆد (Visual Matching Engine):**
  - شیکردنەوەی خێرای وێنە بە پرۆسێسکردنی پەیکەری وێنە و مۆدێلی فرە-بلۆکی (Perceptual Hash / Structural Image Fingerprint & Color Distribution).
  - ڕاستەوخۆ بەراوردی وێنەی نوێ دەکات لەگەڵ وێنەی سەرجەم پاکێجە تۆمارکراوەکان.
  - تەنانەت ئەگەر زاویەی کامێرا کەمێک جیاواز بێت یان ڕووناکی کەمتر بێت، شێوازی لەزگەکە و نووسین و ڕەنگەکانی دەدۆزێتەوە و بە ڕێژەی هاوشێوەیی پلەبەندییان دەکات.
- **تایبەتمەندی وێنەی نموونە:** وێنە سەرەکییەکەی بەکارهێنەر (`IMG-20261028-WA0034_b9150f4a.jpg`) وەک یەکەم کاڵای نموونەیی لە سیستەمەکە دادەنرێت (بە ناونیشانی: هەولێر / مام زاوا، نرخی: 47,000 د.ع، مۆبایلی: 07507496271) بۆ ئەوەی بەکارهێنەر دەستبەجێ تاقی بکاتەوە!

## 4. قۆناغەکانی جێبەجێکردن (Execution Plan)

1. **پێداویستییەکان (Dependencies & Resources):**
   - کاراکردنی `coil-compose` بۆ پیشاندانی وێنەی پاکێجەکان.
   - ڕێکخستنی ناوی ئەپ لە `strings.xml` و `metadata.json` بە ناوی **"پشکنەری بەرید" (Delivery Checker)**.
   - زیادکردنی مۆڵەتی کامێرا (`android.permission.CAMERA`).
2. **پێکهاتەی داتابەیس (Room):**
   - دروستکردنی `ParcelEntity`، `ParcelDao`، و `ParcelRepository` لەگەڵ هەموو فیلدە پێویستەکان و ژماردنی ئاماری دینار.
3. **پەرەپێدانی بزوێنەری ناسینەوەی وێنە (`VisualMatchEngine`):**
   - کۆدکردنی فەرمانەکانی گۆڕینی وێنە بۆ فینگەرپرینتی پەیکەری، بەراوردکردن بە خێرایی بەرز، و دەرهێنانی باشترین هاوتا.
4. **دروستکردنی شاشەکانی UI بە Jetpack Compose:**
   - شاشەی سەرەکی و ئاماری کاڵا نەگەیەندراوەکان.
   - شاشەی زیادکردنی پاکێج و گرتنی وێنە.
   - شاشەی پشکنین و گرتنەوەی وێنە، بەراوردکردن لە چەند چرکەیەکدا، و پیشاندانی دیالۆگی سەرکەوتن بە نرخی 47,000 د.ع لەگەڵ دوگمەی لابردن لە سیستەم.
   - شاشەی ئەرشیفی گەیەندراوەکان.
5. **تاقیکردنەوە و Build:** جێبەجێکردنی `compile_applet` و پشتڕاستکردنەوەی کارکردنی بێ کێشە.
