# پشکنەری بەرید (Delivery Parcel Visual Checker) 📦

ئەپڵیکەیشنی تایبەت بە کارمەندانی بەرید و گەیاندن بۆ تۆمارکردن، نرخ دانان، و پشکنینی خێرای پاکێج بە وێنە بەبێ پێویستی بە بارکۆد.

---

## ڕێنمایی دروستکردنی APK لە ڕێگەی GitHub Actions 🚀

کاتێک پڕۆژەکە دەنێریت بۆ **GitHub** (Push to GitHub)، سیستەمی **GitHub Actions** خۆکارانە کار دەکات و فایلێکی ئامادەی **APK** دروست دەکات:

### چۆن فایلی APK داببەزێنم لە GitHub؟
1. بڕۆ بۆ بەشی **Actions** لە ناو لاپەڕەی ڕیپۆزیتۆرییەکەت لە GitHub.
2. کلیک بکە لەسەر نوێترین کار (Latest workflow run بە ناوی **Build Android APK**).
3. لە بەشی خوارەوە (**Artifacts**)، فایلی **`DeliveryChecker-Debug-APK`** دەبینیت؛ کلیکی لەسەر بکە بۆ دابەزاندنی فایلەکە.
4. فایلەکە بە شێوەی `.zip` دێت؛ بیکەرەوە و فایلی `.apk` بخەرە ناو مۆبایلی ئەندرۆیدەکەت و دایبەزێنە (Install).

---

## تێبینی گرنگ دەربارەی ئەندرۆید (Android) و ئایفۆن (iPhone / iOS) 📱

- **ئەندرۆید (Android - Samsung, Xiaomi, Honor, ...):**
  - فایلی **APK** تەنها و تایبەتە بە مۆبایلەکانی ئەندرۆید.
  - لەسەر هەر مۆبایلێکی ئەندرۆید دەستبەجێ دادەمەزرێت (Install).

- **ئایفۆن (Apple iPhone / iOS):**
  - سیستەمی **iOS** ڕێگە بە دابەزاندنی ڕاستەوخۆی فایلی APK نادات؛ ئایفۆن فۆرماتی **IPA** بەکاردەهێنێت کە پێویستی بە ئەژمێری فەرمی ئەپڵ (Apple Developer Account) و کۆمپیوتەری ماک (macOS / Xcode) هەیە.
  - ئەم پڕۆژەیە بە زمانی ڕەسەنی ئەندرۆید (**Kotlin & Jetpack Compose**) دروستکراوە، بۆیە بۆ بەکارهێنان لەسەر مۆبایلی ئەندرۆید تەواو ئامادەیە.

---

## تایبەتمەندییە سەرەکییەکان:
- 📸 **دەرهێنانی خۆکار بە وێنە (Auto-OCR):** تەنها وێنەی لەزگەی پاکێجەکە بگرە؛ نرخ، ناونیشان و ژمارەی کڕیار بە شێوەی ئۆتۆماتیک دەردەهێنرێت.
- ⚡ **پشکنین بە وێنە (Visual Matcher):** گرتنی وێنەی پاکێج لە شوێنی گەیاندن و بەراوردکردنی ڕاستەوخۆ لەگەڵ کاڵا تۆمارکراوەکان.
- 🗑️ **لابردنی دەستبەجێ دوای گەیاندن:** لابردنی پاکێج لە لیستی چاوەڕوانکراو و ئەرشیفکردنی بە یەک کلیک.
- 📞 **پەیوەندی خێرا:** دوگمەی تەلەفۆنکردن بۆ کڕیار بەبێ نووسینەوەی ژمارە.
- 📊 **ئاماری ڕۆژانە:** ژماردنی کۆی کاڵا ماوەکان، گەیەندراوەکان، و کۆی گشتی پارەی شایستە (IQD).
